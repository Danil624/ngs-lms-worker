# STAGE_1_TZ.md

## Первый этап LMS

Мобильная разработка и отдельное мобильное приложение в первый этап НЕ входят.

### 1. Роли и права

Нужно предусмотреть:
- администратор;
- методолог;
- наставник / куратор;
- сотрудник / обучающийся.

Нужно разграничение доступа к:
- курсам;
- результатам;
- заданиям;
- аналитике;
- административным функциям.

### 2. Фирменное оформление

- логотип;
- название;
- базовое оформление интерфейса.

### 3. Форматы учебного контента

- текст;
- изображения;
- видео;
- аудио;
- PDF;
- DOC/DOCX;
- XLS/XLSX;
- дополнительные файлы.

HTML-виджеты и специальные внешние форматы — только после отдельного согласования.

### 4. Разделы платформы

- онбординг / адаптация;
- обучение по направлениям;
- обучение по темам;
- информирование / новости.

### 5. Треки развития

- последовательные треки;
- открытые треки;
- модули;
- уроки;
- задания;
- тесты;
- итоговый тест;
- завершение.

### 6. Типы курсов

- последовательный;
- открытый;
- потоковый;
- асинхронный.

### 7. Назначение обучения

Назначение:
- сотруднику;
- группе сотрудников;
- подразделению;
- по должности.

Поддержать:
- дату начала;
- дедлайн;
- бессрочный доступ.

### 8. Тестирование

Нужны типы вопросов:
1. один правильный ответ;
2. несколько правильных ответов;
3. текстовый ответ;
4. сопоставление;
5. последовательность;
6. выпадающий список.

Дополнительно:
- банк вопросов;
- случайная выборка;
- проходной процент;
- ограничение попыток;
- таймер;
- сохранение каждой попытки;
- история результатов;
- итоговый тест.

Значения по умолчанию:
- проходной балл — 80%;
- попытки — 2.

### 9. Практические / домашние задания

Сотрудник:
- отправляет ответ;
- прикладывает файлы;
- видит комментарий наставника;
- может повторно отправить задание.

Наставник:
- проверяет;
- принимает;
- возвращает на доработку;
- оставляет обратную связь.

### 10. Сертификаты

Автоматическое формирование PDF после выполнения условий.

Сертификат:
- логотип;
- ФИО;
- название курса;
- дата;
- результат;
- графическая подпись.

КЭП/УКЭП не входит.

### 11. Уведомления

- назначение обучения;
- отсутствие активности;
- напоминание продолжить;
- приближение дедлайна;
- проверка задания;
- возврат на доработку;
- завершение курса.

Каналы и интервалы должны настраиваться.

### 12. Аналитика

Для администратора:
- прогресс;
- завершение;
- средние результаты;
- просрочки;
- сложные вопросы/задания;
- активность наставников;
- статус пользователя.

Для руководителя:
- результаты по подразделению;
- прошёл / не прошёл;
- незавершённые обязательные курсы.

Формулы сложных аналитических показателей должны быть согласованы отдельно.

### 13. AI

Через согласованный внешний API:
- транскрибация;
- черновая генерация тестов;
- помощь при редактировании учебных материалов.

Провайдер, лимиты и стоимость API оплачиваются отдельно.

### 14. Интеграция с Bitrix24

- авторизация;
- сотрудники;
- подразделения;
- роли;
- синхронизация данных;
- работа из корпоративного портала.

### 15. Тестирование и ввод в эксплуатацию

- проверка сквозных сценариев;
- исправление ошибок;
- базовая техническая документация;
- ввод системы в эксплуатацию.

### Не входит в первый этап

- нативное приложение iOS/Android;
- отдельная мобильная разработка;
- геймификация;
- ИПР;
- оценка 360;
- прокторинг;
- КЭДО;
- вебинарная платформа;
- DRM / специализированная защита контента.

Эти функции оцениваются отдельными этапами.
