# PROJECT_CONTEXT.md

## Текущее состояние проекта

Проект — корпоративная LMS на Laravel, интегрированная с Bitrix24.

### Уже реализовано

- MySQL и миграции
- Курсы
- Уроки
- Назначение курсов сотрудникам
- Дедлайны назначений
- Прогресс по урокам
- Итоговые тесты
- Вопросы и варианты ответов
- Попытки прохождения тестов
- Проходной балл
- Журнал активности
- HR-интерфейс
- Страница «Мои курсы»
- Страница курса сотрудника
- Просмотр урока
- Завершение урока
- Расчёт прогресса
- Просмотр результатов обучения

### Bitrix24

Реализована реальная авторизация через Bitrix24.

`BitrixController`:
- получает домен Bitrix24;
- получает AUTH_ID;
- вызывает `user.current`;
- создаёт или обновляет локального пользователя;
- сохраняет Bitrix user ID;
- сохраняет ФИО, email, должность и подразделение;
- создаёт сессию LMS.

Реализована синхронизация сотрудников через `user.get`.

В локальную базу ранее было синхронизировано около 335 сотрудников.

### Роли

Используются роли:
- employee
- hr
- admin

HR-панель должна быть доступна только соответствующим ролям.

### Важные исправления

Для работы внутри iframe Bitrix24 в Blade и редиректах использовались относительные маршруты:
`route(..., false)`

Это было сделано для устранения проблем 403/419 и потери сессии.

### Сессии / iframe

Для работы внутри Bitrix24 использовались настройки:
- `SESSION_SECURE_COOKIE=true`
- `SESSION_SAME_SITE=none`
- `SESSION_PARTITIONED_COOKIE=true`

Не переносить реальные значения `.env` в Git.

### Публичный доступ

Ранее использовались Cloudflare Worker и Tailscale Funnel.

Cloudflare Worker оказался нестабилен в корпоративных браузерах/iframe.

Основным рабочим вариантом был Tailscale Funnel.

Эти адреса являются окружением разработки и не должны становиться частью ядра продукта.

## Важное продуктовое решение

LMS больше не рассматривается только как внутренний проект одной компании.

Цель — сделать универсальный закрытый продукт, который можно продавать другим компаниям как SaaS/лицензию без передачи исходного кода.
